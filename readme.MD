# LitKit - Context Aware, Provider Agnotsic, unix-style AI Assistant

## LitKit is a modular, simple and reliable implementation of an AI personal assistant for your day-to-day and mid-term plans and tasks

### Where does it plug to? 
LitKit can be securily connected to either Telegram or WhatsApp, serving as main UI for interacting with the agent 
### What can it do? 
LitKit can:
1. Support casual conversation and answer general questions
2. Create and manage your calendar events 
3. Plan mid-term personal plans, track and update the progress
4. Log, plan and create nutrition plans depending on your health goals 
5. Conclude research and answer source-grounded questions on topic of interest 
6. Run job search on platforms such as Indeed and LinkedIn 
7. Manage your Inbox
8. Create, manage, and run automation workflows in n8n 
9. Convert repeatable tasks into skills with short commands where applicable
